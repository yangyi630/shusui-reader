# 📖 书髓 - 跨平台阅读精华聚合

> 读过的每一本书，让精华不再被遗忘。

跨平台阅读精华聚合 + AI 学习助手，支持微信读书、番茄读书、Kindle、豆瓣阅读等多平台数据聚合。

---

## 🚀 快速开始

### 环境要求
- Windows 系统
- Python 3.8 或更高版本

### 启动步骤

1. **进入后端目录**
   ```
   打开 backend 文件夹
   ```

2. **双击启动**
   ```
   双击 启动服务.bat
   ```

3. **访问应用**
   - 本机访问：http://127.0.0.1:5000
   - 手机访问：http://你的电脑IP:5000 （手机和电脑需在同一WiFi下）

---

## 📱 手机端使用

### 方法一：浏览器直接访问
1. 确保手机和电脑在同一 WiFi 下
2. 查看电脑 IP 地址（启动服务时会显示）
3. 手机浏览器打开 `http://电脑IP:5000`

### 方法二：添加到主屏幕（PWA）
1. 在手机浏览器中打开应用
2. 点击浏览器菜单 → "添加到主屏幕" 或 "安装应用"
3. 桌面会出现书髓图标，点击即可像 App 一样使用

---

## 🔐 登录方式

### 方式一：扫码登录（推荐）
1. 选择要登录的平台（微信读书/番茄读书/Kindle/豆瓣阅读）
2. 使用对应阅读 App 扫描二维码
3. 在手机上确认授权登录

> 💡 **演示模式**：点击"模拟扫码"按钮可快速体验完整流程

### 方式二：账号密码登录
1. 点击"账号密码"标签
2. 首次使用请先注册账号
3. 登录后可连接各阅读平台

## 🔌 真实 API 对接指南

### 微信读书对接

> ⚠️ **重要提示**：微信读书官方 API 需要企业开发者资质。
> 个人用户可以考虑以下替代方案：

**方案一：浏览器插件方式**
- 开发一个浏览器插件
- 用户在浏览器登录微信读书网页版
- 插件抓取页面数据并同步到书髓

**方案二：导出导入方式**
- 微信读书支持导出划线笔记
- 用户手动导出后上传到书髓

**方案三：第三方 API**
- 使用第三方聚合服务
- 如：知至阅读、微信读书第三方接口

### 配置方式

编辑 `backend/server.py` 或创建 `.env` 文件：

```env
# 微信读书
WEREAD_APP_ID=你的APPID
WEREAD_APP_SECRET=你的APPSECRET

# 番茄读书
FANQIE_APP_ID=你的APPID
FANQIE_APP_SECRET=你的APPSECRET
```

## 🔒 数据安全

- 用户密码使用 MD5 加密存储
- 登录使用 JWT Token 验证
- 数据存储在本地，不上传到第三方
- 局域网访问，数据不暴露到公网

## ❓ 常见问题

**Q: 手机无法访问？**
- 确保手机和电脑在同一 WiFi 下
- 检查电脑防火墙是否允许 5000 端口
- 确认 IP 地址正确

**Q: 服务启动失败？**
- 检查 Python 是否正确安装
- 尝试手动安装依赖：`pip install -r requirements.txt`
- 查看错误信息并反馈

**Q: 如何添加真实平台数据？**
- 当前为演示版本，使用模拟数据
- 如需真实数据对接，请参考「真实 API 对接指南」
- 或通过上传 txt 文档的方式导入

**Q: 数据会丢失吗？**
- 所有数据存储在 `backend/data/` 目录下
- 只要不删除该目录，数据会一直保留
- 建议定期备份 `data` 文件夹
